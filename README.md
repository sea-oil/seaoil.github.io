# C-OIL — The Sea Elixir · GitHub Pages website and Supabase reviews

Version 10 is the retail-only C-OIL website with the approved imagery, a Supabase-backed public review feed, a CAPTCHA-protected review form, and an owner moderation dashboard at `admin.html`.

**Important:** The Supabase backend and Cloudflare Turnstile must be configured and deployed before customers can submit reviews. Until then the form is disabled rather than pretending feedback was saved.

To publish, use the standalone **GitHub Pages ZIP** (without the backend folder). Set `assets/config.js` with your Supabase Project URL, publishable key, and Turnstile site key. Follow the complete guide at `backend/SETUP_GUIDE.md` in the full source package.
